# Portfolio Dante - Backend Developer

Mi portfolio personal como Desarrollador Backend especializado en Laravel y PHP.

## 🚀 Tecnologías

- **Frontend**: Next.js 14, React, TypeScript, Tailwind CSS
- **Animaciones**: Framer Motion
- **Icons**: Lucide React
- **Desarrollo**: ESLint, lint-staged

## 🛠️ Comandos

```bash
# Desarrollo
npm run dev

# Build de producción
npm run build

# Linting
npm run lint

# Preview de producción
npm run start
```

## 📁 Estructura

```
├── app/                    # Next.js App Router
├── components/
│   ├── layout/            # Navbar, Footer
│   ├── sections/           # Hero, Experience, Services, Portfolio, etc.
│   └── ui/                # Componentes reutilizables
├── public/                # Imágenes y recursos estáticos
└── styles/                # Configuración global
```

## 🎨 Personalización

- Colores: Editar `tailwind.config.ts`
- Textos: Componentes en `components/sections/`
- Imágenes: Agregar en `public/`
